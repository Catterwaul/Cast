# ``Cast``

Add typed errors to untyped throwing functions and casting operations.  

### Usage Examples

You've got the source code, so aside from reading this documentation, see the **Tests** folder for example usage! 😺

## Topics

- ``cast(_:)``

### forceCastError

If you control the source for a throwing function, you should  provide its error type. If you don't control the source, use this! Each overload is a mechanism to interface between untyped and typed errors.

- ``forceCastError(to:_:)-hslz``
- ``forceCastError(to:_:)-6560b``
- ``forceCastError(to:_:)-6z9jp``
- ``forceCastError(to:_:)-24a6u``
